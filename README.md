# Cardio Performance Analyzer

A web application for analyzing my cardio performance over the course of my training.

## Why I Built This

I've spent the past year working as a Solutions and Support Engineer. In that time I've learned a lot about helping customers and building internal tools, like RAG pipelines. The role has even pushed me to pick up principles from other engineering disciplines, such as mechanical engineering.

Along the way, though, I noticed that I'd lost my passion for building things outside of work.

I wanted a personal project centered on something I care deeply about, or at least used to: **running**.

I recently bought an Apple Watch Ultra 3, and it got me running again, tracking my runs with Strava. Then it hit me: I could use the Strava API to build my own web app, combining my two passions, software development and running, in one project.

The sections below cover the challenges I faced, the tech stack I used, and the overall architecture.
